# Socket CTF Writeup — Ports 9001–9009

Комплексный разбор и автоматизация серии сетевых CTF-челленджей, основанных на TCP-взаимодействии.
Каждый этап представляет собой сервис, требующий парсинга данных и применения алгоритмов декодирования.

### 🚀 Особенности
    🔌 Работа с реальными TCP-сервисами
    🧠 Автоматическое решение задач (кодировки, математика, шифры)
    ♻️ Переиспользуемая архитектура (DRY)
    ⚡ Один скрипт — все челленджи
---

⚙️ Технологический стек

| Категория     | Инструменты                        |
| ------------- | ---------------------------------- |
| 🐍 Язык       | Python 3.x                         |
| 📦 Библиотеки | `socket`, `re`, `base64`, `codecs` |

---
### 🛠 Архитектура

Решение построено по принципу модульности и переиспользования кода.

Вместо дублирования логики для каждого порта используется единый движок обработки соединений.

---
### 🔑 Ключевые компоненты


| Функция                     | Описание                                              |
| --------------------------- | ----------------------------------------------------- |
| `get_data(s, stop_trigger)` | 📥 Читает данные из сокета до таймаута или стоп-фразы |
| `talk(...)`                 | 🔄 Core Engine: управляет соединением и обработкой    |
| `solve_math_v3 / v8`        | ➕ Решение арифметических выражений через `re`         |
| `solve_caesar`              | 🔐 Дешифровка шифра Цезаря с динамическим сдвигом     |


### 🚪 Этапы решения
🔹 Базовые кодировки


| Порт   | Задача     | Решение                        |
| ------ | ---------- | ------------------------------ |
| `9002` | 🔁 Reverse | `[::-1]`                       |
| `9004` | 🔄 ROT13   | `codecs.decode(..., 'rot_13')` |
| `9005` | 📦 Base64  | `base64.b64decode()`           |
| `9009` | 🔢 ASCII   | `chr(int(x))`                  |


🔹 Логические задачи


| Порт   | Тип       | Описание                    |
| ------ | --------- | --------------------------- |
| `9007` | 🔐 Caesar | Парсинг сдвига + дешифровка |
| `9003` | ➗ Math    | 3 раунда вычислений         |
| `9008` | ➗ Math    | 5 раундов (интерактив)      |

### 📦 Установка и запуск

Клонирование
```shell
git clone https://github.com/augustuz-zeno/socket-ctf-solution.git
cd socket-ctf-solutions
```
Запуск сервера
```shell
python ctf_socket_server.py
```
Запуск всех решений
```shell
python all_challenge_solver.py
```
Запуск отдельного челленджа
```shell
python challenge_solver_N.py
```
Где N — номер челленджа (например: challenge_solver_3.py)

### 📁 Структура проекта
    ├── all_challenge_solver.py   # Запуск всех задач

    ├── ctf_socket_server.py      # Cервер
